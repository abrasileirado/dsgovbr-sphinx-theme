dsgovbr-sphinx-theme
====================

Tema `Sphinx <https://www.sphinx-doc.org/>`_ comunitário e **não oficial** com
visual inspirado no Padrão Digital de Governo (`GOV.BR DS <https://www.gov.br/ds/>`_):
fonte Rawline, cores e tokens do GOV.BR DS, cabeçalho, menu lateral, breadcrumb,
avisos e rodapé no estilo dos componentes do design system, e modo escuro.

.. br-alerta:: warning
   :titulo: Projeto não oficial

   Este tema não representa nem implica homologação ou endosso pelo GOV.BR DS
   ou pelo Governo Federal.

Opcionalmente, a extensão :doc:`componentes` traz **diretivas e roles reST** para
usar nos seus ``.rst`` os componentes do
`dsgovbr-bootstrapped <https://abrasileirado.github.io/dsgovbr-bootstrapped/>`_
(alertas, cards, acordeões, abas, modais...).
